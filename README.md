# Top-Down Racing Game (Android APK)

Jeu de course de voiture en 2D vu du dessus développé en HTML5, JavaScript et Capacitor pour Android.

## Structure du projet
- `www/index.html` : Code source complet du jeu (Canvas, physique, contrôles tactiles).
- `android/` : Projet natif Android généré par Capacitor.
- `android/app/build/outputs/apk/debug/app-debug.apk` : Fichiers APK prêts à être installés sur smartphone.

## Lancer le jeu sur le Web
Ouvrez `www/index.html` dans n'importe quel navigateur web.
